## About Me

I am building **Aegis**, a safety-focused AI computer operator designed to plan, execute, verify and recover from complex workflows.

My primary interest is not merely making agents more capable. I focus on making them **controllable, observable, evidence-backed and reliable**.

- Building an AI operator capable of interacting with development tools and desktop environments
- Designing approval-aware execution boundaries for consequential actions
- Developing structured memory, planning and orchestration systems
- Integrating tools through modular skill and MCP-compatible architectures
- Building execution journals, replay systems and verifiable evidence pipelines
- Exploring safe multi-agent coordination and intelligent model routing
- Creating infrastructure for deterministic, recoverable and auditable automation

## Development Principles

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>Evidence Over Claims</h3>
      <p>
        A successful execution must be supported by artifacts, state changes or independently verifiable results.
      </p>
    </td>
    <td width="50%" valign="top">
      <h3>Approval Before Consequence</h3>
      <p>
        Sensitive or irreversible operations should remain behind explicit authorization boundaries.
      </p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Recovery by Design</h3>
      <p>
        Failures must be diagnosable, replayable and recoverable rather than silently ignored.
      </p>
    </td>
    <td width="50%" valign="top">
      <h3>Observable Intelligence</h3>
      <p>
        Agent decisions, tool activity and execution state should remain inspectable throughout the workflow.
      </p>
    </td>
  </tr>
</table>
